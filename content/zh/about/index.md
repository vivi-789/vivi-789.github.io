## 关于这个知识库

这是一个使用 **Hugo** 和 **PaperMod** 主题构建的个人知识库，托管在 **GitHub Pages** 上。

### 为什么选择这套方案？

| 特性 | 实现方式 |
|---------|-------------------|
| **免费** | Hugo + GitHub Pages = 零成本 |
| **快速** | 静态站点生成 |
| **安全** | Git 版本控制 = 不可篡改的历史记录 |
| **双语** | Hugo 内置多语言支持 |
| **多媒体** | 支持图片、音频、视频嵌入 |
